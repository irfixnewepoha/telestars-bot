# Assumptions

Зафиксированные допущения, принятые при реализации (где промпт оставлял свободу).

1. **aiogram** — закреплена версия `>=3.31.0,<4.0` (актуальная стабильная на момент создания).
2. **Platega** — base URL `https://app.platega.io`, метод СБП = `paymentMethod: 2`, callback-статусы `CONFIRMED` / `CANCELED` / `CHARGEBACKED`, авторизация заголовками `X-MerchantId` + `X-Secret` (сравнение через `hmac.compare_digest`).
3. **Fragment Real client** — в фазе 1–5 используется только `MockFragmentClient`. `RealFragmentClient` оставлен скелетом с явными TODO и правилами безопасности против двойной выдачи. Реализация парсинга/подписи TON требует ручной отладки на реальном аккаунте (см. `docs/FIRST_RUN.md`).
4. **Деньги** — все суммы в БД в целых копейках / nanotons. Отображение в рублях с двумя знаками.
5. **Часовой пояс** — хранение UTC, показ пользователю в Europe/Moscow.
6. **Баланс пользователя** — вычисляется как сумма `balance_ledger`; поле `users.balance_kop` денормализовано и обновляется только в той же транзакции, что и запись ledger.
7. **Один активный неоплаченный заказ** на пользователя (лимит 5 неоплаченных — настраивается позже).
8. **Webhook Telegram** — в dev режиме polling; production — webhook через aiohttp (тот же процесс, что и Platega callback).
9. **TON library** — предпочтение `tonutils` / `pytoniq` для подписи; конкретный выбор при реализации RealFragmentClient.
10. **Минимальная маржа** — `min_margin_kop` применяется после наценки и комиссии платёжки.
