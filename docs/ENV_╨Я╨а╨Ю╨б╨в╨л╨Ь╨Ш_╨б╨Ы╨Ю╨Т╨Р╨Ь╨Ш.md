# Env простыми словами (Railway)

## Как это работает в одном абзаце

Покупатель платит вам (TON через CryptoBot или рубли через Platega).  
Бот видит оплату и **сам** покупает Stars на Fragment с **вашего** TON-кошелька.  
Вы только **пополняете этот кошелёк TON**, когда баланс заканчивается.  
Сотрудник не нужен.

```
Покупатель → CryptoBot/СБП → бот → ваш TON-кошелёк → Fragment → Stars покупателю
```

---

## Список переменных — откуда брать

### Обязательно

| Переменная | Откуда |
|------------|--------|
| **BOT_TOKEN** | Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` → токен вида `7123:AA...` |
| **ADMIN_IDS** | Напишите [@userinfobot](https://t.me/userinfobot) — он покажет ваш id (число). Можно несколько через запятую |
| **TON_MNEMONIC** | 24 слова кошелька, **на котором лежит TON для выдачи Stars**. Создайте отдельный кошелёк в Tonkeeper / Telegram Wallet, запишите seed. Пополните его (1.5+ TON). |

Без `TON_MNEMONIC` автовыдача **не купит** реальные Stars (будет mock/ошибка).

### Оплата — нужен хотя бы один способ

| Переменная | Откуда |
|------------|--------|
| **CRYPTOBOT_TOKEN** | [@CryptoBot](https://t.me/CryptoBot) → меню **Crypto Pay** → **Create App** → скопировать API Token |
| **PLATEGA_MERCHANT_ID** + **PLATEGA_SECRET** | Сайт [app.platega.io](https://app.platega.io) → зарегистрироваться → **Настройки** → MerchantId и Secret |

### Обычно не трогать

| Переменная | Значение |
|------------|----------|
| `FRAGMENT_API_BASE` | `https://api.fragment-api.space` (уже в примере) |
| `STAR_PRICE_RUB` | цена 1⭐ для клиента в рублях, напр. `1.5` |
| `STAR_PRICE_TON` | цена 1⭐ в TON для CryptoBot-счёта, напр. `0.013` |
| `USE_POLLING` | `true` |
| `TON_WALLET_VERSION` | `v4r2` |

### Railway база

1. В проекте Railway нажмите **+ New** → **Database** → **PostgreSQL**  
2. Откройте переменные Postgres → скопируйте `DATABASE_URL`  
3. Вставьте в сервис бота, но замените начало:  
   `postgres://` → **`postgresql+asyncpg://`**  
4. То же с **Redis** → `REDIS_URL` как есть.

## Чего НЕТ и не нужно путаться

- **Fragment API key** (как у некоторых чужих ботов) — нам для схемы с `api.fragment-api.space` **не нужен**. Нужен **сид кошелька** `TON_MNEMONIC`.
- **TON API key** (@tonapibot) — для текущей автовыдачи **не обязателен**.
- Cookies Fragment — опционально (для KYC-режима API).

## Чеклист «заработало»

1. На Railway заданы `BOT_TOKEN`, `ADMIN_IDS`, `TON_MNEMONIC`, `CRYPTOBOT_TOKEN` (или Platega).  
2. На кошельке из мнемоники есть TON.  
3. Один раз **вручную** на [fragment.com](https://fragment.com) купите 50 Stars с этого же кошелька (прогрев).  
4. В боте: купить 50 себе → оплатить → «Проверить оплату».  
5. Должны прийти сообщения: оплата OK → покупка → **Готово, Stars отправлены**.

Если выдача падает — смотрите сообщение админу (часто «мало TON» или сид/тип кошелька).

---

## Ваша модель работы

1. Держите на кошельке запас TON (например на 20–50 заказов).  
2. Бот сам выдаёт после каждой оплаты.  
3. Когда TON заканчивается — пополняете кошелёк.  
4. Рубли/TON от покупателей копятся у вас (Platega / CryptoBot) — выводите когда удобно и снова докупаете TON на кошелёк выдачи.
